# RA3-Copilot 接入 LLM 大模型协同游玩 —— 可行性调研报告

> 对象：`ra3-copilot/`（ra3_1.12.game 日冕 mod，32 位注入型修改器）。
> 触发点：HTTP 调试接口（`127.0.0.1:17832`）已开放，评估 LLM 接入协同游玩的可能性。

---

## 〇、结论先行

**可行，而且我们手里有一副好牌——比"让 AI 从零打游戏"简单一个数量级。**

三句话版本：

1. **执行层已经就绪**：18 个 HTTP 端点覆盖了召唤 / 收编 / 满级 / 无敌 / 摧毁 / 空投 / 免费建造 / 任意内存读写 / 任意函数调用，LLM 的"手"已经接上了。
2. **感知层缺一个口子**：目前只有 RE 视角的诊断输出（`/state`），没有结构化"战场态势"。补一个 `/snapshot` 端点（1~2 天）就够用——**因为我们不需要让 LLM 从零运营，它干的是"神操作"，态势输入可以降级**。
3. **独有杀优势**：单位代码 = `StringHasher.Hash(名字小写)` 已破解、可离线计算 → **LLM 直接说中文单位名就能召唤**，不需要记 772 个哈希。这是别处没有的直通车。

推荐路线：**L1 顾问（只读建议）→ L2 副官（白名单执行）→ L3 托管**，最小 demo 1~2 天可出。

## 一、现有资产盘点

### 1.1 执行能力

| 端点 | 能力 | LLM 用途 |
|---|---|---|
| `/summon?hash=&count=` | 按哈希召唤单位（归属固定本地玩家，落点走"光标→视角中心→选中单位→缓存"优先级链） | 暴兵、救场、空投支援 |
| `/crate?idx=&count=` | 空投箱（54 种：金钱 / 升级 / 治疗 / 属性箱） | 送钱送经验送治疗 |
| `/capture` | 收编选中单位（归属改成本地玩家） | 策反落单敌军 |
| `/kill` `/rank` `/speed` `/health` | 摧毁 / 满级 / 变速 / 无敌（选中驱动） | 救场与整活 |
| `/copy` `/mcv` `/wnb` | 复制选中 / 召唤三阵营基地车 / 预设单位×8 | 一键暴兵 |
| `/freebuild?on=` `/toggle?f=&on=` | 免费建造 / 20+ 功能开关（电力、超武、地图全开、无敌模式…） | 后勤托管 |
| `/poke` `/call` | 任意内存写 / 按 RVA 调函数 | 逃生舱（理论任意） |

### 1.2 感知能力

| 端点 | 现状 | 距"战场态势"的差距 |
|---|---|---|
| `/state` `/diag` | 诊断大体检：基址、符号、相机、落点三来源、**本地队伍 obj/id、资金对象、选中单位结构（类型/坐标/血量/归属）**、模板查找 | 是文本不是结构化数据；**没有资金数值、没有单位枚举** |
| `/log?n=` | 界面输出记录尾部 | 可作为 LLM 的"事件流"输入 |
| `/read` `/peek` `/resolve` | RE 三件套 | 理论上 LLM 可自助探索内存（不推荐，效率低） |

### 1.3 DLL 内已有但未暴露 HTTP 的能力

- `LocalMoney()` / `LocalPlayerId()` —— **资金读取已实现**（读 `g_moneyObj + OFF_MONEY`），只差一个端点。
- `LockSelectedHealth()`（锁定血量，每帧）、`GetFeature/SetFeature`（20+ 开关）、`GetSpawnPos()`（四级落点链）。
- **单位表**：`units_corona.h` = 772 条（718 可玩对象含基准形态标记 + 54 箱子），带阵营/中文名/哈希。

### 1.4 安全底盘

1. `SafeWrite32/Float`：VirtualQuery 校验 + vtable 必须在主模块内 + 数值合理性；
2. dry-run（只记录不写）+ 「禁用游戏函数调用」总闸；
3. `CrashMark` 崩溃面包屑落盘（崩了看文件末尾即知死前动作序列）；
4. HTTP 层 `CmdSlot` 单槽串行 —— **天然就是"一个 LLM 慢慢想、动作排队执行"的模型**，无需额外做并发。

## 二、缺口分析

| # | 缺口 | 说明 | 工作量 |
|---|---|---|---|
| 1 | **`/snapshot` 结构化态势端点** | 返回 JSON：`{资金, 电力, 玩家ID, 选中单位[](类型哈希/坐标/当前血量/上限/归属), 光标世界坐标, 帧号}`。选中单位链表遍历 + 单位名反查（哈希→中文名）已有全部零件，拼装即可 | **低（1~2 天）** |
| 2 | **`/summon` 支持显式坐标** | 目前只能 atMouse（鼠标处）。加 `x,y,z` 参数或 `at=cursor\|selected\|center` 选项，让 LLM 能"投放到指定位置"而非只能蹭鼠标 | **低（半天~1 天）**，`GetSpawnPos` 框架直接扩展一个来源 |
| 3 | **全图单位枚举** | 现在只能遍历"选中链表"。己方全部单位列表需要从 Player 对象找 unit 容器（新 RE） | **高（不确定，数天）**——**但非必须，见下** |
| 4 | **`/screenshot` 视觉输入** | d3d9 Present/EndScene 已 inline-hook，加截图端点技术上很轻；或外挂截图工具（mss）零 DLL 改动 | 低 |
| 5 | **语义动作层** | 现有端点"选中驱动"（capture/kill/rank 都要求先在游戏里选中）。LLM 无法可靠控制游戏内选择框 → L2 阶段要么靠玩家配合选择，要么补"按单位 id 操作" | 中 |

### 关键判断：LLM 协同 ≠ 让 AI 从零打游戏

普通"AI 打游戏"需要全图感知 + 移动/攻击微操，那是另一个量级的工程。**我们是修改器，LLM 的打法是"神操作"**：

- 不需要枚举全图单位——**选中单位 + 资金 + 光标位置 + （可选）截图**就是足够的上下文；
- 不需要移动/攻击指令—— summon / crate / rank / health / capture 每一个都自带"改变战局"的语义；
- 玩家负责"正常游玩"（选择、移动、建造），LLM 负责"超常支援"（暴兵、送箱、满级、救场）。

**认知分工 = 玩家管操作，LLM 管因果律。** 这是本项目做 LLM 协同的核心思路，缺口 3 因此可以无限期搁置。

## 三、分级路线图

### L1 顾问模式 —— 零风险，1 天出 demo

- LLM **只读**（`/snapshot` + 可选截图）→ 文字建议，**不执行任何变更**。
- 例：「电差 40，建议先补一座电厂」「检测到选中单位血量 12%，建议后撤」。
- 价值：跑通"游戏 → 态势 → prompt → LLM → 建议"全管道，验证延迟与 prompt 质量。**崩不了任何东西。**

### L2 副官模式 —— 低风险，推荐首发形态

- LLM 通过 **function calling** 输出结构化动作 → 本地执行器翻译成 HTTP 调用：
  - `summon(unit="磁暴坦克", count=3, at="cursor")` → 查表拿哈希 → `POST /summon?hash=..&count=3`
  - `crate(kind="治疗")` / `capture()` / `rank()` / `suggest(text="……")`
- **白名单分级**：`summon/crate/rank/health/freebuild` 等安全动作自动执行；`kill/capture/poke/call` 需玩家一键确认（或玩家在场时全放权）。
- **限速**：执行器层 2 次/秒封顶（CmdSlot 本来就串行，这是双保险）。
- 体验：玩家前线微操，LLM 后方运营 + 关键支援——**"AI 战友"**。

### L3 托管模式 —— 中高风险，体验好再上

- LLM 每 3~5 秒自主决策并执行（无确认）。
- 前置条件：L2 稳定运行一周 + 待验证项③（召唤单位"未入世"）已解决 + dry-run 先跑通。
- 护栏：INSERT 菜单常驻「AI 暂停」开关、动作计数上限、CrashMark 全程取证。

### L4 全自动对战 —— 暂不推荐

- 需要缺口 3 + 移动/攻击 order 结构 RE，工作量大、且脱离了修改器的乐趣（都自动了还改什么）。

## 四、架构设计

```
┌────────────────┐  GET /snapshot   ┌───────────────┐  function calling  ┌──────────┐
│  ra3copilot.dll│ ───────────────▶ │  LLM Bridge   │ ────────────────▶ │  任意 LLM │
│  (游戏进程内)   │                  │  (Python 独立) │ ◀──────────────── │  API      │
│  127.0.0.1:17832│ ◀─────────────── │               │   动作 JSON        └──────────┘
└────────────────┘  POST /summon…   └───────────────┘
        ▲                                   │
        │ 玩家正常游玩                        │ 白名单 / 限速 / 确认 / 日志
```

**LLM Bridge（独立 Python 进程，建议落位 `research/llm-bridge/`）**

- 轮询 `/snapshot`（默认 3s，可调；与游戏帧率解耦）；
- prompt 组装：system（角色设定："你是玩家的星际副官，口头禅是同志"）+ 态势 JSON + **可用动作目录**（单位表按阵营/类型分组的常用子集 + 哈希，**不全量塞 772 条**，用检索式注入）；
- 调 LLM（任何支持 function calling 的 API：DeepSeek / GLM / Kimi / Step / GPT；本地 Ollama 14B 也够做指令翻译）；
- 执行器：单位名 → 哈希（**离线 StringHasher 直算，零延迟**）→ HTTP POST；
- 全部动作 + LLM 原始回包落盘（`llm_bridge.log`），复盘用。

**DLL 侧最小改动集**

1. `/snapshot` 端点（缺口 1）；
2. `/summon` 加坐标参数（缺口 2）；
3. （可选）`/units?q=` 单位名→哈希查询（桥接层其实可离线算，此端点主要给"只带一个 DLL 的现场"用）；
4. （可选）`/screenshot`（缺口 4）。

**LLM 选型要点**：副官节奏是"秒级决策"，1~3s 延迟无感；优先选 function calling 稳定 + 中文好的。token 成本：每次决策 ~2~4K tokens，一局 1 小时 ≈ 几百次决策 ≈ 几块钱量级（DeepSeek 级）。

## 五、技术风险与对策

| 风险 | 说明 | 对策 |
|---|---|---|
| **闪退** | LLM 生成坏参数 / 高频调用 | 三层护栏已铺；CmdSlot 天然串行；限速；L3 前必过 dry-run |
| **召唤物"未入世"** | 已知待验证项③：新建单位 vtable 不同、状态位全 0，对它们再操作会失败 | **L2 阶段只用已验证动作**（summon 本体是验证过能生成的）；顺手解决待验证项③ |
| **LLM 记不住单位** | 772 个哈希 | 名→哈希离线可算 + prompt 检索式注入相关子集 |
| **上下文膨胀** | 战场数据量大 | 分层：每 tick 小快照 + 定期"大事记"摘要；只给附近/重要信息 |
| **决策延迟 vs RTS 实时** | LLM 秒级，游戏帧级 | 架构分层：LLM 管战略节奏（秒级），微操永远归玩家 |
| **误操作不可逆** | kill/capture/poke | 白名单分级 + 确认模式 + CrashMark 取证 |
| **LLM 幻觉** | 编不存在的单位/动作 | 执行器严格查表校验，未知单位名直接拒绝并回喂错误让 LLM 自重试 |

## 六、协同玩法构想

1. **AI 战友**：玩家前线微操，LLM 自动空投治疗箱到残血单位旁、给精锐满级、收编落单敌军、免费建造补后勤。
2. **嘴硬司令员**：LLM 用指挥官口吻播报战况（"同志，敌方钢铁洪流已逼近第二矿区！"）——顺便真的给你派来支援。
3. **挑战模式**：限定 LLM 只能出箱子和中立单位，玩家限兵种，双人博弈。
4. **战役顾问**：截图（多模态）+ 任务目标 → 打法建议 + 关键节点空投支援。
5. **防守训练陪练**：LLM 周期性召唤敌军攻打玩家基地，模拟高压防守训练。

## 七、结论与建议路线

| 阶段 | 内容 | 周期 | 风险 |
|---|---|---|---|
| **Demo** | `/snapshot` + Python bridge + **L1 顾问**（只读只建议） | 1~2 天 | 零 |
| **第一阶段** | L2 副官：function calling + 白名单执行 + `/summon` 坐标参数 | 3~5 天 | 低 |
| **第二阶段** | L3 托管 + 视觉输入（截图多模态）+ 解决"未入世" | 视体验 | 中 |

**DLL 改动排序**：`/snapshot`（感知，一切的地基）→ `/summon` 坐标参数（精准投放）→ `/screenshot`（视觉，可选）。

**一句话**：接口已经开到"LLM 只要会说话就能玩游戏"，剩下的是给它一双眼睛（snapshot）和一张单位词典（我们早破解了）。这个真能做。
