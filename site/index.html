/ 01

作战辅助系统

不是外挂式的作弊器，而是一套「可观测、可干预、可被 AI 驱动」的战术面板。挂载点采用「特征码 + RVA」双通道定位，愿景是覆盖红色警戒3 的全部版本。

Ra3-Copilot 以注入方式在游戏进程内运行，直接用游戏自己的渲染设备绘制菜单 —— 不弹独立窗口、不抢焦点、切出游戏也不会静音。

它由三部分组成：功能核（表驱动的内存挂钩，负责资源 / 战斗 / 单位操作）、 渲染层（inline-hook 游戏渲染管线，把面板画在画面内）、 副官接口（进程内 HTTP + MCP，让 AI 读取战局并下达指令）。

所有写入类操作都经过安全护栏，且只在你主动触发时执行；注入前对每个挂载点做 特征码字节级校验，不匹配就拒绝挂载。

/ 03

系统架构

功能核（内存挂钩）+ 渲染层（inline-hook）+ 副官接口，三层协作。

injector.exe (x86) ──CreateRemoteThread(LoadLibraryW)──► ra3copilot.dll (in-game)
                                                            │
                     ┌──────────────────────────────────────┼────────────────────────┐
                     ▼                                      ▼                        ▼
            features 功能核                          overlay 渲染层             httpapi / mcp 副官接口
            表驱动挂钩（名/RVA/AOB/壳）               读 d3d9 vtable[16/17/42]        进程内 HTTP 127.0.0.1:17832
            push-ret 与 E9 detour                    → MinHook inline-hook           MCP stdio 服务器
            壳（MASM）→ 改内存 / 记录对象              → Present 内渲染 ImGui          → AI 读战局 / 投放部队
/ 04

快速上手

需要先进入对局；注入器与游戏同为 32 位。

STEP 01

启动游戏

通过启动器进入对局（遭遇战 / 战役均可）。

STEP 02

注入

运行 ra3-copilot\deploy.bat，自动提权并注入，随后打印诊断。

STEP 03

呼出面板

游戏内按 INSERT 显示菜单，F7 加钱。

/ 05

脑机接口

把进程内能力包装成标准 MCP 工具，让 AI 客户端成为你的副官。

工具作用
get_battle_state我方 / 敌方兵力、资金、选中单位
search_units单位检索（中文名 / 模板名 / 哈希）
summon_unit投放单位
drop_crate空投补给箱
selected_action复制 / 增援 / 基地车 / 收编 / 摧毁 / 满级
toggle_feature资源 / 战斗 / 地图类开关
{
  "mcpServers": {
    "ra3-copilot": {
      "command": "python",
      "args": ["<仓库>/ra3-copilot/mcp/ra3_mcp.py"]
    }
  }
}

默认总闸关闭时 AI 只能观战；在游戏内面板开启后，AI 才被允许下达变更指令。
